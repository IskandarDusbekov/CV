{% icon "check-circle" %} Google'da chiqish uchun qadamlar

  1. Google Search Console (search.google.com/search-console) → «URL prefix» → {{ host }} → ikki usuldan biri:
    • HTML file — Google bergan fayl nomini (google….html) «Google HTML fayl nomi» maydoniga yozing. Faylni yuklab, serverga joylash shart emas;
    • HTML tag — content="…" ichidagi kodni «Google Search Console kodi» maydoniga qo'ying.
    Saqlang va Google'da «Verify» bosing.
  2. Search Console → Sitemaps → sitemap.xml yozib yuboring.
  3. Yandex Webmaster (webmaster.yandex.ru) — xuddi shunday: kod + sitemap.
  4. Search Console → «URL inspection» → bosh sahifa va /namunalar/ uchun «Request indexing».
  5. Bepul statistika: Google Analytics yoki Yandex Metrika ID sini qo'ying — qaysi so'zlar bilan kelishayotganini ko'rasiz.
  6. Har hafta panelda yangi namuna qo'shing (hozir {{ samples_count }} ta) — har biri Google'da alohida so'rov bo'yicha chiqadi.
  7. Telegram kanal, guruh va boshqa saytlarda {{ host }}/namunalar/… va /qollanma/… havolalarini ulashing — tashqi havolalar reytingni ko'taradi.

{% icon "hourglass" %} Google yangi saytni odatda 2–8 haftada indekslaydi, raqobatli so'rovlarda yuqoriga chiqish 3–6 oy oladi. Hech kim «doim 1-o'rin»ni kafolatlay olmaydi — lekin foydali sahifalar soni va sifati eng katta ta'sir qiladi.
